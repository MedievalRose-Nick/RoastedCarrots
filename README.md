# Roasted Carrots

A tiny Minecraft Bedrock add-on: cook carrots in a furnace, smoker or campfire into a Roasted Carrot (6 hunger, 12 saturation).

- Wiki: https://nicholasambrose.github.io/RoastedCarrots/
- Download: [addon/RoastedCarrots.mcaddon](addon/RoastedCarrots.mcaddon)

Build: `node tools/build.mjs` (add `--deploy` to copy into your local Minecraft dev packs).
